# Coleta e etiqueta

**O que é:** Jejum, volume, hemólise e etiqueta Code 128.

**Preparo:** `Bancada__CookiesSeguros=false ASPNETCORE_URLS=http://127.0.0.1:5099 dotnet run --project src/Bancada.Web -c Release`

## Roteiro (serve de guião do vídeo)

1. Como Coleta, abra /coletas e procure PED-000045.
2. Informe jejum de 2 h: recusado (RN-022).
3. Informe volume 0,1 mL: recusado (RN-023).
4. Colete certo: abre a etiqueta. Imprima.

## O que há por trás

Code 128 gerado no servidor por código próprio, com teste de ida e volta.

## Destaque para o vídeo

Etiqueta nascendo do pedido.

## Critério

Sem erro no console, sem 4xx inesperado, sem rolagem horizontal em 400 px, claro e escuro.

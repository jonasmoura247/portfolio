IA — servidores MCP próprios

TypeScript · Model Context Protocol · 4 servidores

  • code-review-mcp: carrega as diretrizes de código do projeto e faz a revisão pré-commit, com anotações na linha do problema, severidade e veredito aprovado/reprovado.
  • sonar-review-mcp: mesma revisão, com regras no estilo SonarQube para C#, JavaScript/TypeScript, HTML e CSS.
  • pr-comments-mcp: lista os comentários pendentes de um Pull Request do Azure DevOps e responde a cada um, marcando como resolvido.
  • pr-replicate-mcp: busca os arquivos de um PR e aplica só as linhas alteradas no clone local, sem sobrescrever em caso de conflito.
  • Nenhum segredo ou caminho no código: token e repositório vêm de variáveis de ambiente.
